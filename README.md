## What is this repository?

This repository is my personal playground and knowledge base for exploring Vue.js and its ecosystem, collecting
examples and notes from what I learn that may help others facing similar challenges.

The content reflects my personal
perspective and may contain inaccuracies.

## What topics are covered?

- Vue 3 and Vite
- Nuxt
- Quasar and Vuetify
- TypeScript in Vue applications
- Shared ESLint configuration and development tooling
- Project setup and framework notes
