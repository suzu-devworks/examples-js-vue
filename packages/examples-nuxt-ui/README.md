# examples-nuxt-ui

[![Nuxt UI](https://img.shields.io/badge/Made%20with-Nuxt%20UI-00DC82?logo=nuxt&labelColor=020420)](https://ui.nuxt.com)

Nuxt 4 application with Nuxt UI.

## Purpose

Try building a landing page with Nuxt UI components, including its header, hero, feature sections,
and dark-mode controls. The app is based on the [Nuxt UI starter template](https://github.com/nuxt-ui-templates/starter).

## Stack

- Nuxt 4 / Vue 3
- Nuxt UI 4
- Pinia
- Tailwind CSS 4

## Getting started

Run from the repository root:

```sh
pnpm install
pnpm --filter examples-nuxt-ui dev
```
